## Working principles

- Uploaded/current source files are the source of truth.
- Work should generally be delivered as full replacement packs or small documentation packs, not loose patch fragments.
- The `docs/` folder must be kept current for human readability and future chatbot handoff.
- Final website copy should be written by Taylor Pike, not AI-generated by default.
- The project is Vite + TypeScript + vanilla modules + Three.js, not React.
- The local editor is Flask-based under `local-editor/`.
- Active data lives in `src/data/`.
- Runtime images use rendition folders under `public/images/portfolio/`.

### Phase 2 — Public-site polish

Status: Complete

The public shell was polished across homepage, portfolio index, global navigation, responsive behavior, mobile hero performance, and lightbox interaction/accessibility.

Important Phase 2 outcomes:

- Homepage is currently hero-only.
- Homepage should not require scrolling on normal 1920x1080 desktop screens.
- VCR/pixel font is scoped to minor accent usage only.
- The header/wordmark remains on the normal site font.
- The portfolio meta strip no longer has the awkward gallery CTA button.
- The red portfolio header underline was removed.
- Mobile homepage spacing/content density was improved.
- Mobile hero performance was improved with smaller image delivery and less eager preloading.
- Lightbox focus and mobile swipe behavior were improved.
