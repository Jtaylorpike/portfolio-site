# Phase 8S — Surface Texture Enhancement

## Summary

Phase 8S continues from the accepted Phase 8R balance and cleanup state. The goal of this pass is to add more subtle surface character across the room before any additional warmth or shadow work is attempted. The two main texture targets are a faint matte-marble or polished-stone floor read and a very restrained gritty/chipped-paint ceiling texture that hints at the original mockup without becoming loud or obviously procedural.

## Scope

- preserve the current lighting architecture and frame/floating-geometry fixes;
- increase subtle material character across the room;
- push the floor toward a faint matte-marble read with low-contrast veining;
- add a very subtle gritty / chipped-paint ceiling texture;
- keep wall texture restrained and avoid obvious seam or grid artifacts;
- keep room geometry, collision, plaque fallback, controls, editor logic, assets, dependencies, routing, public copy, dynamic shadow maps, transparent shadow planes, post-processing, and fog out of scope.
