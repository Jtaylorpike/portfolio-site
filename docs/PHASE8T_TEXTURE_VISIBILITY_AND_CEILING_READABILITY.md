# Phase 8T — Texture Visibility and Ceiling Readability

## Summary

Phase 8T continues from the Phase 8R/8S visual baseline. The user reported that the Phase 8S textures did not feel noticeable and that the ceiling was still too dark. This pass makes the floor/wall/ceiling procedural surface treatment more legible while keeping it restrained, and lifts the ceiling toward readable warm charcoal so the gritty/chipped-paint texture can actually be seen.

## Scope

- increase floor/wall/ceiling material texture visibility;
- push the floor further toward faint matte marble / polished stone;
- make the ceiling brighter and more readable while preserving the dark dramatic atmosphere;
- add a more legible gritty/chipped-paint ceiling texture;
- keep object shadows deferred to the next focused pass;
- keep room geometry, collision, plaque fallback, controls, editor logic, assets, dependencies, routing, public copy, dynamic shadow maps, transparent shadow planes, post-processing, and fog out of scope.
