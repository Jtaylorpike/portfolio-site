# Pack Notes — Phase 8X Texture Reference and Loading Prewarm Correction

## Apply

Copy/extract the contents of this pack directly into the project root and overwrite matching files.

## Intent

This is a root-relative replacement pack intended to be applied on top of the current Phase 8V + Phase 8W source state.

## Summary

- makes wall/floor/ceiling textures more visible in normal gallery views;
- disables ceiling shadow receiving to reduce grid-like ceiling lines;
- adds material texture prewarming so gallery loading feels less frozen;
- preserves room layout, collision, plaque fallback, controls, editor logic, routing, and deferred copy/branding work.
