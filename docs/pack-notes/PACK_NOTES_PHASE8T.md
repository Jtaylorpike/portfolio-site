# Pack Notes — Phase 8T Texture Visibility and Ceiling Readability

## Apply

Copy/extract the contents of this pack directly into the project root and overwrite matching files.

## Intent

This is a root-relative replacement pack intended to be applied on top of the current working Phase 8S source state.

## Summary

- makes procedural surface textures more visible;
- pushes the floor further toward faint matte marble;
- brightens the ceiling toward readable warm charcoal;
- makes the ceiling gritty/chipped-paint texture more legible;
- keeps object shadows deferred to the next focused pass;
- preserves room layout, collision, plaque fallback, controls, editor logic, routing, and deferred copy/branding work.
