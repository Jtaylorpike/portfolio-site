# Pack Notes — Phase 6F Mobile Camera + Landscape Home Tuning

## Summary

This is a narrow Phase 6 follow-up. It reduces touch camera sensitivity from the Phase 6E setting while keeping the more responsive Phase 6E movement behavior. It also adds a short landscape-phone homepage layout guard so the hero is usable when a phone is held horizontally.

## Apply

Copy the files in this pack over the matching paths in the repository root.

## Validation run

- `npm ci --ignore-scripts`
- `npm run build`
- CSS brace-balance check
- Static Phase 6F source checks
- `unzip -t`

## Notes

This pack does not change gallery curation data, editor data models, wall placement, collision behavior, plaque metadata, About/contact behavior, or desktop gallery controls.
