# Pack Notes — Phase 8Q Cooled Lighting and Surface Texture Refinement

## Apply

Copy/extract the contents of this pack directly into the project root and overwrite matching files.

## Intent

This is a root-relative replacement pack. It is intended to be applied on top of the current working Phase 8P source state.

## Summary

- shifts the room cooler and more neutral;
- adds subtle deterministic wall/floor surface texture with no external assets;
- keeps the floor largely matte with a restrained reflective response;
- keeps the Phase 8 dramatic-lighting architecture intact;
- preserves room layout, collision, plaque fallback, controls, editor logic, routing, and deferred copy/branding work.
