# Pack Notes — Phase 8R Warmth and Texture Seam Cleanup

## Apply

Copy/extract the contents of this pack directly into the project root and overwrite matching files.

## Intent

This is a root-relative replacement pack intended to be applied on top of the current working Phase 8Q source state.

## Summary

- smooths the visible floor/wall texture seam grid;
- adds a bit more warmth back into the room;
- lightens the frame palette so dark wood does not read as flat black;
- removes the floating bottom frame strip;
- preserves room layout, collision, plaque fallback, controls, editor logic, routing, and deferred copy/branding work.
