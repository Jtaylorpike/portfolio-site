# Pack Notes — Phase 5E About Background Float Positioning

## Summary

This pack refines the public About/contact page background-float layer. The float images are now positioned more aggressively so most of them spill off the browser edges, while one float sits slightly off-center near the page middle for depth.

## Manual test

1. Open the public About/contact page.
2. Confirm the background-float images are visibly large.
