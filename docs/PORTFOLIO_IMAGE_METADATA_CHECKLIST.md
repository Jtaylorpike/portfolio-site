# Portfolio Image Metadata Checklist

Date: 2026-05-14
Purpose: Practical checklist for Phase 3 image/content curation

## Core image decision

For each image, first decide its status:

- Public now
- Hide for now
- Replace later
- Remove from project
- Keep as archive/reference only

Do this before spending time on detailed metadata.

## Required or strongly recommended fields

For each public image, review:

- Image ID
- Title
- Category
- Source/display image paths
- Thumbnail path
- Texture path
- Full-size path
- Orientation/crop behavior
- Hero eligibility
- Gallery eligibility
- Hidden/public status

## Public-facing metadata

Prioritize fields that improve browsing and credibility:

- Title
- Year
- Location
- Category
- Short descriptive alt text

Avoid overlong captions unless the final site intentionally adds deeper image notes later.

## Hero-readiness checklist

A hero candidate should generally be:

- Landscape or crop-safe.
- Strong as a first impression.
- Legible beneath the existing overlay/treatment.
- Not dependent on small details that disappear on mobile.
- Fast enough through the existing rendition pipeline.
- Consistent with the editorial/gallery-index visual direction.

Avoid making too many images hero-eligible. The homepage is stronger when it feels selected.

## Portfolio-index checklist

A portfolio-index image should:

- Represent work Taylor wants public.
- Have a clean thumbnail crop.
- Belong clearly to a category.
- Not look like test/import filler.
- Not create category imbalance unless intentional.

## 3D-gallery checklist

A 3D gallery image should:

- Be worth encountering in the slower immersive gallery context.
- Have metadata/plaque information that is usable.
- Be placed where the user can reasonably approach and inspect it.
- Not create plaque collision or spacing problems.
- Work with the room's current museum/private-archive feeling.

The 3D gallery does not need to use every public image.

## Alt text guidance

Alt text should be descriptive and useful. It should not be stuffed with SEO phrases.

Good pattern:

```text
A concise description of the visible subject, setting, or action.
```

Avoid:

```text
Taylor Pike Productions best photography portfolio commercial photographer...
```

## Category guidance

Categories should be useful to a visitor. They should not simply mirror folder names or import history.

A good category is:

- Understandable without explanation.
- Broad enough to contain multiple strong images.
- Specific enough to guide browsing.

## Metadata pass order

Recommended order:

1. Public/hide/remove decision
2. Category
3. Title
4. Hero eligibility
5. Gallery eligibility
6. Location/year
7. Alt text
8. Final sequencing/curation notes

## Stop point

It is acceptable to finish only a portion of Phase 3 before launch if the finished portion feels intentional. A smaller curated portfolio is better than a larger unfinished archive.
