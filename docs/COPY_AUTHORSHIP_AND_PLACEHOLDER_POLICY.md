# Copy Authorship and Placeholder Policy

Generated: 2026-05-13

## Purpose

This document records the copy ownership rule for the Taylor Pike portfolio site so future chats and human developers do not accidentally replace the user’s voice with AI-generated final website copy.

## Core rule

The user wants to create the final website copy personally.

AI-generated text may be used for:

- internal documentation
- changelogs
- technical notes
- placeholder labels
- structural planning
- copy inventories
- questions/prompts that help the user write

AI-generated text should not be treated as final public-facing website copy unless the user explicitly approves it.

## Areas requiring user-authored final copy

Highest priority:

- About page heading
- About page body text
- Career journey text
- Photography/project statement text
- Contact/service language

Also user-controlled:

- homepage intro copy
- entry page headline/body copy
- portfolio page intro copy
- gallery CTA explanatory language
- mobile gallery instructions/fallback text
- metadata/microcopy where tone matters

## Acceptable development approach

Future packs may create page structure and placeholder slots such as:

- `[About page heading goes here]`
- `[Project statement copy goes here]`
- `[Contact/service copy goes here]`

Future packs may also preserve existing copy temporarily if removing it would create unnecessary churn.

## Unacceptable development approach

Do not replace the About page or major public sections with polished AI-authored prose and present it as final. Do not invent biographical statements, client positioning, or artist statements without the user’s explicit direction.

## Practical implication for upcoming phases

Phase 2 public polish should focus on structure, typography, layout, interaction, and placeholders. Phase 5 About/contact redesign should build the visual system and content containers while leaving final prose for the user.

Phase 2B followed this rule: it changed CSS and documentation only, with no public copy changes.
